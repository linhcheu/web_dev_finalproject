# careconnect_boss

CareConnect: hospital appointment platform (Laravel 12).

| Folder | App |
|---|---|
| `frontend/` | Patient + hospital-admin website (owns the database migration + seeders) |
| `backend/` | Platform admin panel |
| `api/` | JSON API (optional) |

## Deploying to a DigitalOcean Droplet (Cloud Computing Mission 4b)

Follow **[deploy/MISSION_4B_DEPLOY.md](deploy/MISSION_4B_DEPLOY.md)**. It includes the Apache vhosts, production `.env` templates and a final-check script.
